# Privacy Policy – ILSRP Discord Bot **Last updated:** 14 November 2026 ## 1. Introduction This Privacy Policy explains how the ILSRP Discord Bot ("the Bot") collects, uses, stores and protects information when used in Discord servers. By using the Bot, you acknowledge this policy. ## 2. Information We Collect The Bot may collect and store the following information: - Discord user IDs and server IDs. - Discord usernames and server configuration information. - Role IDs and channel IDs used for permissions and logging. - Ticket information and transcripts. - Moderation records, including warnings and staff actions. - Roblox usernames and Roblox user IDs when verification features are used. - ER:LC private server API keys supplied by authorized server administrators. - ER:LC server information and player data when requested through the Bot. ## 3. How We Use Information Information is used exclusively to: - Provide the Bot's features and commands. - Manage tickets, moderation and staff systems. - Verify Roblox accounts. - Connect to ER:LC private servers. - Execute authorized ER:LC management commands. - Maintain security and prevent abuse. - Troubleshoot technical problems. ## 4. Storage and Security Configuration and operational information may be stored in the Bot's database. ER:LC API keys are stored as part of the relevant Discord server's configuration and are not intentionally displayed in public responses. We take reasonable measures to protect stored information. However, no online service can guarantee absolute security. ## 5. Data Sharing We do not sell personal information. Information may be processed by Discord, Roblox and the ER:LC API when necessary to provide requested functionality. Server administrators may access information generated by the Bot within their own Discord server, subject to their permissions. ## 6. Data Retention and Deletion Information is retained only as long as reasonably necessary to provide the Bot's services and maintain operational records. Discord server administrators may request the removal of their server's stored configuration and associated data by contacting the Bot's developer. Some records may remain in backups or logs for a limited period. ## 7. Third-Party Services The Bot interacts with third-party services, including: - Discord - Roblox - Emergency Response: Liberty County (ER:LC) API These services have their own privacy policies and terms. ## 8. Changes to This Policy This Privacy Policy may be updated when the Bot's features or data practices change. The latest version will be published at this URL. ## 9. Contact For privacy-related questions or data deletion requests, contact the Bot's developer through the official ILSRP Discord support server.
